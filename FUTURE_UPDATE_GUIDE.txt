GOVIND PERSONAL VAULT - FUTURE UPDATE RULES

Current release:
- VERSION_NAME=1.2.1
- VERSION_CODE=5
- Package=com.govind.personalvault

For every later version:
1. Start only from the latest FutureProof public source ZIP.
2. Increase app/version.properties VERSION_CODE: 5 -> 6 -> 7 ...
3. Update VERSION_NAME: 1.2.1 -> 1.2.2 / 1.3.0 / 2.0.0 as appropriate.
4. Keep package com.govind.personalvault unchanged.
5. Preserve DB/encryption compatibility; add tested migrations for schema or format changes.
6. Keep exactly one Govind_Personal_Vault_GitHub_Public_Repo_v*.zip in the GitHub repository.
7. Do not edit the workflow or four secrets for a normal app update.
8. Never upload the private signing kit, keystore, passwords, Base64 key, PIN, recovery phrase, vault DB, or private media.
9. Run Actions -> Build signed APK -> Run workflow on main.
10. Download the artifact and install with Update; do not uninstall the existing app.

The workflow automatically detects the source ZIP, project folder, Gradle/SDK versions, app version, APK filename, and artifact name.
