GOVIND PERSONAL VAULT v1.2.1 (versionCode 5)
FULLSCREEN CANVAS + PLAYER GESTURES PRE-BUILD AUDIT
================================================================

Scope
-----
This package updates the successfully built v1.1.0 source without changing the package ID,
signing identity, existing SQLite schema, or encrypted GVM2 file format.

Requested device-test fixes
---------------------------
1. Landscape dashboard content was cramped and unreachable.
   - The programmatic dashboard now uses a ListView header/footer composition.
   - Stats, category tabs, search, items, empty state, and the add button participate in one
     vertically scrollable surface.
   - A ListView is not nested inside a ScrollView.

2. Landscape video playback left too little space for the video.
   - Added programmatic Media3 PlayerView integration with its built-in controller disabled.
   - The underlying SurfaceView remains secure.
   - Landscape video hides system bars, the app title/metadata chrome, and export/delete actions.
   - Added Fit, Zoom, and Fill resize modes.
   - Playback controls auto-hide after 3.5 seconds while video is actively playing and return on tap.

3. Documents could not be locked.
   - Added DocumentsVaultActivity and SecureDocumentActivity.
   - Added multi-select Storage Access Framework import for non-media documents.
   - PDFs, office documents, text files, archives, and unknown non-media file types can reuse the
     existing authenticated encrypted-file engine.
   - Photos/videos/audio are rejected by the Documents importer and remain in Media Vault.
   - Document metadata remains encrypted in the existing media_items table; no schema migration is
     required.
   - Explicit export decrypts directly into Downloads/Govind Personal Vault through MediaStore.
   - No plaintext temp preview, ACTION_VIEW, FileProvider, broad storage permission, or external
     decrypted-file handoff was added.

Honest remaining gates
----------------------
The current container does not contain the Android SDK, Gradle distribution, or Maven dependency
cache, so it cannot authoritatively run AGP/Media3 compilation. The next source-of-truth gate is the
existing pinned GitHub Actions workflow. A green cloud build must then be followed by device tests:
- portrait/landscape dashboard scrolling,
- video rotation and tap-to-show controls,
- Fit/Zoom/Fill rendering,
- audio playback,
- PDF/DOC/TXT/ZIP import,
- lock during import/export,
- export to Downloads,
- delete and relaunch,
- low-storage/corruption behavior,
- update installation without uninstalling the currently installed app.
